# Medicine Expiry Tracking & Alert System

A simple DevOps-focused web application to track medicine inventory and alert
users about medicines nearing expiry or already expired.

## Problem Statement
Pharmacies and small medical stores often struggle to track expiry dates of
stocked medicines manually, leading to expired medicines being sold or wasted.
This system automates expiry tracking and status alerts.

## Features
- Add / Edit / Delete / View / Search medicines
- Automatic expiry status calculation (Safe / Expiring Soon / Urgent / Expired)
- Dashboard with inventory statistics

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- Containerization: Docker, Docker Compose
- Infrastructure as Code: Terraform
- Configuration Management: Ansible
- Cloud: AWS EC2
- CI/CD: GitHub Actions
